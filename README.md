# 🌍 Tourism Dashboard

A showcase dashboard to explore global differences and similarities in vacation behavior based on international survey data.

Developed by **Raffael Ruppert** (Research & Data Scientist) for demonstration and methodological purposes.

---

## 📊 Methodologies Applied 
- **Z-Test**: Significance testing across countries
- **Max-Diff Analysis**: Identifying key differences in preferences
- **K-Means Clustering with PCA Loadings & Z-Score Normalization**: Segmenting countries by attitudes
- **Dendrogram Clustering**: Hierarchical clustering of countries based on vacation behavior
- **NPS (Net Promoter Score)**: Measuring satisfaction with recent vacations
- **Boxplot Analysis**: Exploring distribution of satisfaction ratings
